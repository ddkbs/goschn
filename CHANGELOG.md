# Changelog

## 0.3.0

- The app is now called Goschn (it was Rüber)
- New, much simpler panel in light and dark
- Fixed: the panel could be cut off when opened a second time
- New app icon

## 0.2.0

- Translate between any two supported languages, not only to English
- Detects the language you type; text in the target language goes back to yours
- Language menus in the panel, `⌘1`…`⌘5` for recent targets
- Command line: `--from` and `--to`

## 0.1.0

- Floating panel with live on-device translation to English
- Global shortcut (default `⇧⌘Space`), changeable in the menu
- Enter pastes into the previous app, `⌘↩` copies only
- Swap direction with Tab, choose your language in the menu
- Launch at login, command line mode
